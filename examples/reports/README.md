# 离线测评报告示例

[下载 / 查看 HTML 文件](mai-edit-report.html)。GitHub 文件页面可能显示源码；请下载原文件，或下载仓库 ZIP 后双击 `examples\reports\mai-edit-report.html`，用浏览器离线打开。报告内有“打印 / 另存为 PDF”按钮。

这是 **MAI Image 2.5 与 MAI Image 2.6** 对同一张非敏感物体图进行编辑的真实报告。指令是只把黄色杯子改为绿色，保留其他物体、背景、形状、位置和光照。两个模型使用相同规范化输入，分别返回 1024 × 1024 PNG。

| 内容 | 本例情况 |
| --- | --- |
| 原始任务 | 一张参考图、一条英文编辑指令，两模型并行，各一次 |
| 实际耗时 | MAI Image 2.5：26.233 s；MAI Image 2.6：20.399 s |
| 图像 | 内嵌共同原图及两个原始输出，可离线阅读，无 CDN / 服务端依赖 |
| 人工评分 | **尚未评分**，各项保持“未评分 / N/A”，没有补分 |
| 报告解析 | 只描述已保存的运行记录和证据限制，不自动看图推断质量 |
| 隐私处理 | 不含私人 endpoint、订阅、部署别名、原始错误或人工评语；原图 / 输出已检查无嵌入元数据 |

这个示例展示**报告能力**，不是自动量化评测、正式质量排行榜或稳定速度结论。只有一个源图和一个任务，无法代表多样客户场景；多个模型输出也不能当作多个独立客户样本。

报告是导出时的静态快照，之后在网页里更改评分不会更新这个文件。需要新版时重新导出即可，原始快照仍可留存。真实客户的图片、提示词和备注必须逐次审核后才能外发，不能因为有这份公开示例就自动公开后续结果。
